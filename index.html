03 / the science

Six ways a personal formula fails.
We model all six first.

When the base or the combination changes per person, classical testing can’t keep up: a stability study alone takes months. So every OSEE formula passes six computational screens before it reaches a chemist, then a bottle.

Screen 01Predictive

Stability

Predicts phase separation, viscosity drift and pH shift for each base-and-active combination, so only qualified bases are used.

→ pass / hold · predicted shelf window
Screen 02Rule + model

Preservation

Checks that the preservative system still protects a formula it was not originally tuned for, with airless packaging as the default.

→ challenge-risk score
Screen 03Pairwise

Active compatibility

Screens every pair of actives for known and predicted interactions, and bounds the combination space before it is searched.

→ n / n pairs clear
Screen 04Permeation

Delivery

Estimates how much of each active crosses the skin barrier in this vehicle, not on an idealized membrane.

→ delivered-dose estimate
Screen 05Sensory

Texture

Predicts feel, spread and finish across skin types and climates, trained on what customers actually report.

→ sensory profile
Screen 06Combination

Sensitization

Standard methods assess single substances. We validate each active once, then screen the full combination against your exclusions.

→ exclusions present: 0
04 / the platform

More than a quiz.
Built around chemistry.

Three layers that only work together. The diagnostic front end is the part anyone can copy. The engine, the library and the response data are what make the formula yours.

Layer 01

The engine

Machine-learning formulation models that predict how a formula will behave, and search for the best one inside a pre-cleared safety envelope.

  • Property prediction: stability, viscosity, pH
  • Constrained search over bases × actives × doses
  • Every distinct formula stays within regulatory limits
Layer 02

The library

A structured set of actives and qualified bases, each validated once with its own dossier, so combinations can change without a new safety case.

  • Per-active dossier and dose limits
  • Qualified bases with stability data
  • Proprietary actives added over time
Layer 03

The dataset

Consented, structured response data: a known dose of a known active, measured on a real person over weeks. Nobody in the category collects it.

  • Fixed 0–4 scales at weeks 3, 4 and 8
  • Per-person dose-response, updated each cycle
  • Consent written like a study from day one
